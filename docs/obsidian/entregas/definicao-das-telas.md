# Definição das telas

Função responsável: [[analista-de-negocios]]

## O que é

As 15 telas do sistema definidas por referência visual, cada uma com a
implementação esperada declarada.

## Evidência no projeto

`aquapulse-kit-claude-sistema/MAPA-DE-REFERENCIAS.md` mapeia referência →
implementação esperada:

| Referência | Implementação esperada |
| --- | --- |
| `visao-geral/01-…-represa-selecionada.png` | visão geral de uma represa selecionada |
| `visao-geral/02-…-todas-as-represas.png` | visão consolidada com todas as represas |
| `monitoramento/01-volume-de-vazao.png` | afluência e defluência |
| `monitoramento/02-nivel-do-reservatorio.png` | nível, cota, capacidade e tendência |
| `monitoramento/03-ph.png` | qualidade da água e faixa ideal de pH |
| `monitoramento/04-volume-armazenado.png` | volume armazenado e balanço hídrico |
| `monitoramento/05-precipitacao.png` | precipitação observada e prevista |
| `monitoramento/06-previsao-duracao-agua.png` | previsão em diferentes cenários |
| `monitoramento/07-situacao-operacional.png` | disponibilidade e manutenção |
| `monitoramento/08-comparativo-vazao.png` | comparação entre períodos |
| `demais-telas/03-relatorios.png` | relatórios, filtros e histórico |
| `demais-telas/04-niveis.png` | visão ampla dos níveis e limites |
| `demais-telas/05-mapas.png` | localização interativa |
| `demais-telas/06-alertas.png` | central de alertas e eventos |
| `demais-telas/07-configuracoes.png` | empresas, represas, indicadores e limites |

O documento também define o que **deve ser recriado em código** em vez de
recortado das capturas: gráficos, linhas de limite, mapa, ícones, cards,
tabelas, badges, filtros e menus.
