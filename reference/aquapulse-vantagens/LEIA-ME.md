# Kit Aquapulse — vantagens

Substituição da última seção de conteúdo da landing page, mantendo o rodapé.

## Como usar

1. Extraia o ZIP.
2. Coloque a pasta `aquapulse-vantagens` dentro de `references/` no seu projeto. Se você já organiza as referências em `reference/`, use essa pasta existente.
3. Abra o projeto no Claude Code e envie o texto abaixo, ajustando apenas o nome da pasta se necessário.

```text
Leia references/aquapulse-vantagens/IMPLEMENTAR-VANTAGENS.md e implemente a substituição da última seção de vantagens da landing page. Use referencia-vantagens.png para comparar o layout e aquapulse-vantagens-fundo.png como fundo. Recrie os textos e o botão em HTML/CSS reais, conforme as instruções. Preserve as demais seções e deixe o resultado pronto para revisão local.
```

## O que há no pacote

| Arquivo | Uso |
| --- | --- |
| referencia-vantagens.png | Cópia da imagem aprovada com composição, textos e CTA. |
| aquapulse-vantagens-fundo.png | Foto preparada sem os elementos de interface, para uso na página. |
| IMPLEMENTAR-VANTAGENS.md | Instruções completas para o Claude Code. |
| LEIA-ME.md | Este guia. |

O fundo foi preparado com remoção dos textos e reconstrução visual das regiões cobertas. Por isso pode apresentar pequenas diferenças locais em relação à referência. Não é uma camada original extraída de um arquivo de design.

O pacote contém a referência e os materiais de implementação. Ele ainda não altera os arquivos do seu site.
